# Site de Produtos - Vitrine Geral

Aplicação web desenvolvida com **React** e **TypeScript** para exibição de produtos, busca e gerenciamento de favoritos.

## Sobre o projeto

O projeto foi desenvolvido como trabalho interdisciplinar, aplicando conceitos de programação orientada a objetos, princípios SOLID, GRASP e consumo de APIs externas.

## Funcionalidades

- Página inicial
- Listagem de produtos
- Busca de produtos
- Favoritos
- Consumo de APIs externas
- Organização com models, controllers, interfaces e components

## Tecnologias utilizadas

- React
- TypeScript
- Vite
- React Router DOM
- React Toastify
- HTML
- CSS

## Conceitos aplicados

- Programação orientada a objetos
- Herança
- Interface
- Polimorfismo
- Organização em camadas
- Separação de responsabilidades

## Como executar

Clone o repositório:

```bash
git clone https://github.com/Juliasacht/Site-de-Produtos-Vitrine-Geral.git
```

Acesse a pasta do projeto:

```bash
cd Site-de-Produtos-Vitrine-Geral
```

Instale as dependências:

```bash
npm install
```

Inicie o projeto:

```bash
npm run dev
```

Acesse no navegador o endereço exibido no terminal.
